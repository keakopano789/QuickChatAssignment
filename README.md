# QuickChatAssignment

This project is a Java console application for user registration and login validation.

## Features
- Validates username format (must contain underscore, max 5 characters).
- Validates password complexity (minimum 8 characters, includes uppercase, number, and special character).
- Validates cell phone number in international format (+27 followed by 9 digits).
- Captures first name and surname for a personalized welcome message.

## How to Run
1. Open the project in NetBeans.
2. Run `QuickChatAssignment.java`.
3. Follow the prompts to enter your details.
